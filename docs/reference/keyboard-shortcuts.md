# Keyboard shortcuts

Default shortcuts. All keyboard shortcuts can be remapped under **Edit → Preferences →
Shortcuts**: click an entry and press the new key combination. Mouse navigation and the keys
inside the Node Editor are fixed.

## Viewport navigation

| Action | Input |
|---|---|
| Orbit | `Alt` + left-drag |
| Pan | `Alt` + middle-drag |
| Zoom | `Alt` + right-drag, or mouse wheel |
| Frame mesh | `F` |
| Frame cursor | `Shift+F` |
| Rotate environment | `Shift` + right-drag |
| View: Split / 3D / UV | `F1` / `F2` / `F3` |

In the [UV view](uv-view.md#navigation), `Alt` + left-drag pans instead of orbiting, and `F`
frames the used tiles.

## Fields

| Action | Input |
|---|---|
| Change a value | Drag in the field |
| Fine steps | `Ctrl` + drag |
| Type a value | Double-click, then `Enter` (`Esc` cancels) |

See [Controls](windows-and-panels.md#fields).

## Curves

With the [Curve](curves.md) tool:

| Action | Input |
|---|---|
| Add a point / start a curve | Click on the mesh |
| Close and finish | Click the first point |
| Finish | `Enter` or `Esc` |
| Remove the last point | `Backspace` (while drawing) |
| Select a curve | Click it |
| Move a point | Drag it |
| Insert / delete a point | `Ctrl` + click the line / the point |
| Delete the selected curve | `Delete` |

## Paint buffer

| Action | Input |
|---|---|
| Bake | `Ctrl+B` |
| Toggle Live / Manual | `Ctrl+Shift+B` |
| Clear buffer | `Ctrl+Delete` |
| Move / rotate / scale buffer | Hold `V` + left-drag / `Shift` / `Ctrl` |
| Reset buffer transform | `V`, `R` |

## Stencils

## Node Editor

While the pointer is over the Node Editor, these keys apply there. The full list, with mouse
gestures and what each operation does, is in [Node Editor](node-editor.md).

| Action | Input |
|---|---|
| Add node | `Tab`, or right-click empty space |
| Open a layer group | Double-click it |
| Frame selected nodes / take them out of their frames | `F` / `Alt+P` |
| Add reroutes on the links crossed | `Shift` + right-drag |
| Node menu | Right-click a node |
| Box select / pan | Left-drag empty space / right-drag or `Alt` + left-drag |
| Preview node output | `Ctrl+Shift` + click |
| Lazy connect | `Alt` + right-drag (with `Shift`: choose sockets) |
| Cut links | `Ctrl` + right-drag |
| Merge selected | `Ctrl+0` mix, `Ctrl++` add, `Ctrl+-` subtract, `Ctrl+8` multiply, `Ctrl+/` divide, `Ctrl+,` min, `Ctrl+.` max |
| Swap | `Alt+S` |
| Dissolve / delete / delete unused | `Ctrl+X` / `Delete` / `Alt+X` |
| Copy / paste nodes | `Ctrl+C` / `Ctrl+V` |
| Align top / left / bottom / right edges | `Shift+W` / `Shift+A` / `Shift+S` / `Shift+D` |
| Align in a row or column | `Shift+=` |
| Collapse / expand selected | `H` |
| Link active to selected | `K` |
| Copy settings / reset | `Shift+C` / `Backspace` |
| Select all / none | `A` / `Alt+A` |
| Frame all nodes | `Home` |
