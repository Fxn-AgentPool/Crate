# Keyboard shortcuts

Default shortcuts. All keyboard shortcuts can be remapped under **Edit → Preferences →
Shortcuts**: click an entry and press the new key combination. Mouse navigation and the Node
Editor keys are fixed.

## Viewport navigation

| Action | Input |
|---|---|
| Orbit | `Alt` + left-drag |
| Pan | `Alt` + middle-drag |
| Zoom | `Alt` + right-drag, or mouse wheel |
| Frame mesh | `F` |
| Frame cursor | `Shift+F` |
| Rotate environment | `Shift` + right-drag |

## Display

| Action | Input |
|---|---|
| Material view | `M` |
| Cycle channels | `C` |
| Cycle mesh maps | `Shift+C` |
| Toggle UDIM tile grid | `U` |
| Toggle wireframe | `W` |

## Tools and brush

| Action | Input |
|---|---|
| Paint | `B` |
| Erase | `E` |
| Paint Through | `P` |
| Smaller / larger brush | `[` / `]` |
| Softer / harder brush | `Shift+[` / `Shift+]` |
| Interactive size / flow | `Ctrl` + right-drag |
| Pick color | `Alt+Shift` + click |

## Paint buffer

| Action | Input |
|---|---|
| Bake | `Ctrl+B` |
| Toggle Live / Manual | `Ctrl+Shift+B` |
| Clear buffer | `Ctrl+Delete` |
| Move / rotate / scale buffer | Hold `V` + left-drag / `Shift` / `Ctrl` |
| Reset buffer transform | `V`, `R` |

## Stencils

| Action | Input |
|---|---|
| Toggle stencil visibility | Tap `S` |
| Move / rotate / scale stencil | Hold `S` + left-drag / `Shift` / `Ctrl` |
| Flip stencil horizontally | `S`, `H` |
| Reset stencil transform | `S`, `R` |
| Next stencil | `Alt+S` |

## Layers and graph

| Action | Input |
|---|---|
| New paint layer | `Ctrl+Shift+N` |
| New fill layer | `Ctrl+Shift+F` |
| Group selected | `Ctrl+G` |
| Duplicate | `Ctrl+D` |
| Delete | `Delete` |
| Edit as graph | `G` |
| Back to Layers panel | `Esc` (in Node Editor) |
| Add node | `Tab` or right-click (in Node Editor) |
| Delete node | `Delete` (in Node Editor) |
| Frame all nodes | `Home` (in Node Editor) |
| Select several layers | `Ctrl` + click |

## File and history

| Action | Input |
|---|---|
| New project | `Ctrl+N` |
| Open project | `Ctrl+O` |
| Save | `Ctrl+S` |
| Export textures | `Ctrl+E` |
| Undo | `Ctrl+Z` |
| Redo | `Ctrl+Shift+Z` |
