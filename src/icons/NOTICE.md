# Interface icons

The files here are Blender's interface icons, copied unchanged from the Blender repository
(https://projects.blender.org/blender/blender, commit
`754ebe3c4b4e1402a159df6e1e58823cc93ef887`, Blender 5.4 alpha):

- `*.svg`: from `release/datafiles/icons_svg`.
- `*.dat`: toolbar icon geometry from `release/datafiles/icons` (stored with Git LFS there).

`brush_data.svg`, `filebrowser.svg`, `file_refresh.svg`, `image_alpha.svg`, `image_data.svg`,
`mesh_data.svg`, `node_material.svg`, `viewzoom.svg` and `world.svg` were added later, unchanged, from
`release/datafiles/icons_svg` at commit `8cd8e62c575617d7fc89eed5d2c56bdfe0043819`.
